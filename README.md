# Tessera

The singular Lucidity Vault. V1: KV-secrets core (Vault KV-v2-compatible REST, token auth,
path-scoped policies, append-only audit, seal/unseal). RustyVault-backed, crypto pinned to
OpenSSL/native-Rust. Design spec: see the Galvo repo `docs/superpowers/specs/2026-06-14-tessera-vault-v1-design.md`.
